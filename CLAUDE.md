**Read `docs/SOURCE_OF_TRUTH.md` before doing anything.** It is the single source of truth for what we are building, why, for whom, with which data, and what we are not allowed to claim. If a request conflicts with it, say so and stop.

## Layout
- `engine/` : Python 3.11 (Nitu). `recommend/` ranker and feedback templates, `aggregate/` k-anonymous cells and dip detector, `api/` (FastAPI), `fixtures/` (JSON), `tests/`. Glucose modules (`model/`, `attribution/`, `optimize/`, `eval/`) are parked.
- `app/` : React 19 + Vite + TS + Tailwind + shadcn + Zustand + Recharts (Azra). Map is Google Maps when `VITE_GOOGLE_MAPS_API_KEY` is set, Leaflet otherwise. Runs on fixtures when `VITE_USE_FIXTURES=1`.
- `data/` : public seed data (`rutgers_resources.json`, `academic_calendar_fall2026.json`) and `synthetic/` (generated by `scripts/`, labelled synthetic). Raw downloads go in `data/raw/` and are git-ignored.
- `infra/` : `aws/` hosts the app (engine on App Runner, app on S3 + CloudFront; `infra/aws/deploy.sh`). Geocoder pass (Amazon Location or Azure Maps) to replace approximate coordinates; run from a laptop.
- `scripts/` : data generators. Re-run and commit outputs together.
- `docs/` : this project's truth.

## Hard rules
1. No PHI. Ever. Public datasets or synthetic data only.
2. No number in UI, slides, or docs without a primary source. The engine attaches `source` to every metric; the app renders it on hover.
3. Wellness tool, not clinical. No diagnosis language, no red/orange/green fear UI. Tone: friendly, strengths-based. Forbidden words list in `docs/SOURCE_OF_TRUTH.md` 2.5.
4. Staff never see an individual. Cells with n < 5 are suppressed in the engine.
5. Resources rank by fit first, distance second. The closest is not always first.
6. Only name a sponsor service (AWS, Google Maps) on a slide if it is actually running in the demo.
7. `main` always runs. Branch per task. Small single-purpose commits with readable messages. No em dashes in commits or docs.
8. Feature freeze Saturday 10 PM. After that: bug fixes, deck, rehearsal only.
